## 繁體中文

- 同一個 Windows 安裝版支援繁體中文與英文，可從設定選單立即切換並記住選擇。
- 啟動時在背景檢查最新正式版，提供下載更新、稍後提醒與略過版本；離線仍可分析。
- 保留既有光譜擬合、Condition 趨勢、PL 疊圖、Figure Template、Excel／圖片／Origin 資料包匯出功能。
- Windows 10／11 x64；安裝版包含 Python 與必要套件。
- 安裝更新前請儲存專案並關閉 PL Studio。

下載 `PL-Studio-Setup.exe`；`SHA256SUMS.txt` 提供安裝檔校驗碼。

## English

- One Windows installer includes Traditional Chinese and English, with immediate language switching and a saved preference.
- Background startup checks offer Download, Later and Skip for newer stable releases. Analysis remains available offline.
- Includes spectrum fitting, Condition trends, PL overlays, Figure Template, and Excel / figure / Origin data bundle exports.
- Windows 10 / 11 x64; Python and required libraries are included.
- Save projects and close PL Studio before installing an update.

Download `PL-Studio-Setup.exe`. `SHA256SUMS.txt` contains its SHA-256 checksum.
